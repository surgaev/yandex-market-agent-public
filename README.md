# ym-agent — аналитика продавца Яндекс Маркета

Собирает данные из Partner API и строит Excel-отчёт: движение денег,
денежный вклад заказов, услуги Маркета, буст и остатки FBS/FBY.
Деньги и справочные баллы учитываются отдельно.

## Установка одной командой

Нужен [uv](https://docs.astral.sh/uv/) (`curl -LsSf https://astral.sh/uv/install.sh | sh`).

```bash
uv tool install git+https://github.com/surgaev/yandex-market-agent-public
ym-agent init
```

`init` создаст в `~/.ym-agent/` два файла:

- `.env` — ключ API и ID кабинета (подсказки, где их взять, внутри);
- `cost_prices.csv` — закупочные цены: `артикул,цена`, можно править в Excel.
  Префикс покрывает все варианты: `ABC123` → `ABC123-red`, `ABC123-xl`.

Заполните их и запускайте:

```bash
ym-agent run              # отчёт за сегодня → ~/Downloads/ym_report_ГГГГ-ММ-ДД.xlsx
ym-agent run --en0        # macOS: в обход VPN, если он режет доступ к API
```

Попробовать без установки: `uvx --from git+https://github.com/surgaev/yandex-market-agent-public ym-agent init`.
Обновиться: `uv tool upgrade ym-agent`. Вместо uv подойдёт `pipx install git+…`.

Ключ API создаётся в кабинете продавца: Настройки → API и модули. Нужны доступы
к статистике, финансам, заказам, товарам и остаткам, продвижению.

Первый прогон долгий: отчёт «По платежам» генерируется на стороне Яндекса, а
помесячная история набирается в кэши в `~/.ym-agent/`.

## Что в отчёте

- **Сверка выплат** — платежи, услуги, возвраты и итог по SKU/FBS/FBY.
  Проведённые, отправленные и ожидаемые суммы разделены; баллы отдельно.
- **Деньги по месяцам** — товары по строкам, месяцы блоками столбцов,
  итоги за период. Дополнительные статусы раскрываются через группы колонок.
- **Экономика заказов** — платежи и услуги одного заказа, себестоимость,
  денежный вклад до и после резерва. Плюс/минус и неполные расчёты выделены цветом.
- **Вклад заказов по месяцам** — результат по месяцу оформления с числом
  рассчитанных и неполных позиций.
- **Финансовые операции** — детализация для проверки статусов и итогов.
- **Юнит-экономика** — разбор комиссий на штуку, стоимость буста, предел ставки.
- **Скидки FEE по заказам** — где скидка за участие в акциях не покрыла размещение.
- **Воронка** — показы, клики, корзины, покупки по дням (14 дней), «дырявая воронка».
- **Остатки FBS/FBY** — динамика по дням, на сколько дней хватит, что дозаказать.
- **Ставки буста по дням**, индекс цен, логистика по регионам, качество карточек и отзывы.

## Методика финансов

Движение денег группируется по дате транзакции. Оно не равно прибыли:
платежи и услуги одного заказа могут попасть в разные периоды.
Отменённые и неизвестные статусы не включаются в проведённые деньги.

`денежный вклад = платёж покупателя + денежные компенсации − услуги − себестоимость`

- Доходы и услуги связываются по модели работы и номеру заказа. Для нескольких
  товаров услуги распределяются по цене × количеству с сохранением суммы.
- Справочные баллы показаны отдельно. Расходы сохраняются при отмене/невыкупе.
- Возвраты, незавершённые заказы и недостающие данные дают пропуск,
  а не нулевую прибыль. Общие расходы бизнеса не включены.
- Себестоимость берётся из текущего CSV. Резерв задаётся `YM_TAX_RATE`
  (по умолчанию 0.07); это расчётное допущение, не налоговая декларация.
- Рабочее окно финансов — последние 89 дней до вчерашнего дня; доступность
  истории зависит от кабинета. Граничные месяцы неполные.
- Новый кэш `finance_cache_v2` отделён от старых агрегатов и исключён из Git.
  Исходные XLSX сохраняются локально для сверки; данные обновляются ежедневно.
- Поля акций `*_promo` не считаются бустом. Доли буста берутся из
  `shows_boost_pct` / `orders_boost_pct`, средние взвешены количеством.
  Недоступный показатель не подменяется нулём.

## Расписание на macOS

Шаблон — `launchd/ym-analytics.plist.example`: подставьте путь из `which ym-agent`,
скопируйте в `~/Library/LaunchAgents/` и загрузите через `launchctl load`.

## Разработка

```bash
git clone https://github.com/surgaev/yandex-market-agent-public && cd yandex-market-agent-public
uv run ym-agent run
```

В `docs/` сохранены иллюстрации прежнего оформления на выдуманных данных;
они не отражают текущую финансовую методику.
