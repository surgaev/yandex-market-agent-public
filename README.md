# yandex-market-agent

Агент аналитики для продавца на Яндекс Маркете. Раз или два в день собирает
данные из Partner API и строит Excel-отчёт: сколько реально зарабатывает
каждый артикул после всех комиссий, буста, баллов, себестоимости и налога.

## Что в отчёте

- **Сверка выплат** — чистая прибыль на штуку по каждому артикулу за 30 и 90 дней
  по отчёту «По платежам» (united-netting): что Яндекс реально перечислил, минус
  себестоимость и налог. Взвешенная оценка (0–30 дней ×2, 31–90 дней ×1).
- **Прибыль по месяцам** — штуки, прибыль и ₽/шт по месяцам; закрытые месяцы кэшируются.
- **Юнит-экономика** — разбор комиссий на штуку, стоимость буста, предел ставки.
- **Скидки FEE по заказам** — где скидка за участие в акциях не покрыла размещение.
- **Воронка** — показы, клики, корзины, покупки по дням (14 дней), «дырявая воронка».
- **Остатки FBS/FBY** — динамика по дням, на сколько дней хватит, что дозаказать.
- **Ставки буста по дням**, индекс цен, логистика по регионам, качество карточек и отзывы.

## Установка

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env                        # вписать ключ API и ID кабинета
cp cost_prices.example.py cost_prices.py    # вписать закупочные цены по артикулам
```

Ключ API создаётся в кабинете продавца: Настройки → API и модули. Нужны доступы
к статистике, финансам, заказам, остаткам и продвижению. `YM_BUSINESS_ID` и ID
кампаний видны в адресной строке кабинета.

## Запуск

```bash
./run_agent.sh                 # прогон: блокировка от двойного запуска, ожидание зарядки, проверка сети
./run_agent.sh --if-missing    # только если сегодняшнего отчёта ещё нет (догоняющий запуск)
```

Отчёт появится в `YM_REPORT_FOLDER` как `ym_report_ГГГГ-ММ-ДД.xlsx`.
Первый прогон долгий: отчёт «По платежам» генерируется на стороне Яндекса, а
помесячная история набирается в кэши (`*.json` рядом со скриптом).

`run_via_en0.py` — разовый запуск в обход VPN на macOS (исходящие соединения
привязываются к Wi-Fi-интерфейсу en0), если VPN режет доступ к API.

### Расписание на macOS

Шаблон — `launchd/ym-analytics.plist.example`: поправить путь, скопировать в
`~/Library/LaunchAgents/` и загрузить через `launchctl load`.

## Методика прибыли

`прибыль = К перечислению − себестоимость × (продано − возвраты) − налог 7% × выручка`

- Себестоимость списывается только с выкупленных штук: возврат уезжает на склад.
- Окна отчёта «По платежам» у Яндекса пересекаются (в выгрузку попадают и более
  ранние операции), поэтому строки фильтруются строго по дате операции.
- Буст оплачивается частично с бонусного баланса — колонка «Буст NET» показывает
  только денежную часть.
